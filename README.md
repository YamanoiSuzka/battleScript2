## EXゲージ

- EXは消費型ステータスの参照値30（最大値）・31（現在値）を使用します。戦闘中の最大値はプラグインが30に設定するため、キャスト側の成長値が0でも蓄積できます。
- 通常攻撃は1行動につきEX＋1。追加攻撃回数や対象数では増えません。スキルはコストを支払って実行できた時に加算します（ミスでも加算、コスト不足時は加算なし）。
- 敵から正のHPダメージを受けるたびにEX＋1。回復・ミス・0ダメージ・毒などの継続ダメージでは加算しません。EXは30を超えません。
- スキルの「管理タグ＋メモ」欄に `EX増加量: 3` のように1行で記入すると、そのスキルの獲得量を指定できます。未指定・不正な値は1、`EX増加量: 0` は加算なしです。指定できる実効値は0～30です。
- EXスキルはデータベースの消費ステータス設定で「EXの消費値」を10にしてください。Bakin標準のコスト判定によってEXが10未満の時は使用できず、使用時に10消費します。EXスキルでEXを獲得させたくない場合はメモに `EX増加量: 0` を指定してください。

### レイアウトとの連動

バトルステータスの「キャスト1」～「キャスト4」には、レイアウトツールでそれぞれ「EXバー」を配置してください。プラグインはEXバーを新規配置・複製せず、配置済みのバーの特殊書式を各キャストの `\partysp[0][31]` ～ `\partysp[3][31]` に設定します。参照値31が現在値、参照値30がその最大値です。

リソースのスプライト「EX」を、既存の「EXレベル背景」（143×21）の3つのひし形の中心に重ねます。EXが10・20・30に達すると左から1・2・3個が表示され、到達時に `SE_Item_Use_03` を1回再生します。1回の更新で複数の境界へ到達した場合もSEは1回だけです。消費して境界を下回ると対応するアイコンは即時に消えます。戦闘画面を最初に開いた時は現在値へ即時同期し、SEを再生しません。スプライトに設定された出現・消滅モーションは使用しません。画像・ゲージとも親コンテナの移動や表示状態に追従します。

EXアイコンの補完は戦闘中のメモリ上のレイアウトに行い、`Layout.rbr` は書き換えません。このため、追加したアイコンはレイアウトツールの編集画面には表示されません。位置調整は各キャストに配置した「EXバー」の位置・サイズを変更してください。「EXバー」がないキャストには、バーもアイコンも追加されません。Bakinのテストプレイを再起動して反映を確認できます。

# CTB拡張タグ

## ボス撃破演出

モンスター（キャスト）の「タグ」欄に `#Boss` を追加すると、HPが0になった際、画面を2回フラッシュさせ、地鳴りのような効果音とともにモンスターを小刻みに左右へ震わせながら赤くします。その後、敵消滅効果音と設定済みの消滅エフェクトを再生します。タグは大文字・小文字を区別しません。

## 連続行動スキル

スキルの「タグ」欄に次のタグを追加すると、そのスキルが正常に実行された直後、使用者がもう一度行動できます。

```
#ctb_consecutive
```

- スキルのコストを支払えず実行に失敗した場合、連続行動は発生しません。
- 連続行動で同じタグ付きスキルを再度使うと、さらに連続行動できます。

## 空のスキル発動演出の省略

スキルの「タグ」欄に次のタグを追加すると、設定内容にかかわらず共通の発動演出を省略します。

```
#ctb_skip_activation
```

次の両方を満たすスキルは、共通の発動メッセージ、モーション、効果音、スキルカメラ、待機時間を省略して効果処理へ進みます。

- スキル固有の使用時メッセージが未設定
- ゲーム定義の「スキル発動エフェクト」が未設定

どちらか一方でも設定されている場合は、従来どおりの発動演出を行います。

## モーションとエフェクトの同期

スキルの「タグ」欄に次のタグを追加すると、スキル発動から20フレーム待って使用モーションを開始し、その開始に合わせて対象エフェクトの処理へ進みます。

```
#エフェクト同期
```

- スキルカメラは従来どおり先に開始します。
- 使用モーションは20フレーム経過後に開始します。
- 味方・敵・クリティカルの対象エフェクトは、使用モーションが開始したことを確認してから表示します。
- このタグがないスキルは従来どおりのタイミングで動作します。

## 発動待機の短縮

スキルの「タグ」欄に次のタグを追加すると、発動時の待機を約20フレームに固定し、スキルカメラの終了を待たずに効果処理へ進みます。

```
#短縮
```

- 決定ボタンやメッセージウィンドウの有無では20フレームより短くなりません。
- `#エフェクト同期` と同時に指定した場合は、モーションとエフェクトの同期処理を優先します。
- 以前使用していた `#近接攻撃` は短縮タグとして認識されません。

## スキル使用者の残像

スキルの「タグ」欄に次のタグを追加すると、使用者のスキルモーション中に残像を表示します。

```
#残像
```

- 2Dビルボードの使用者だけが対象です。3DモデルとLive2Dでは残像を表示しません。
- 残像は3フレーム間隔で生成され、15フレームかけてフェードアウトします。
- 同時に表示する残像は最大2枚、生成時の透明度は80%です。
- 残像は生成時の座標とモーション姿勢で停止し、本体とは別のビルボードとして描画されます。
- 使用者が前回の生成位置からほとんど動いていない場合は、同じ場所への重複生成を行いません。

## 状態変化ポップアップ

状態が付与・解除された時、対象キャストの近くに状態アイコンと名前を表示します。解除時の表示だけを省略したい状態には、次のタグを追加します。付与時の表示は通常どおり行われます。

```
#解除時非表示
```

HPが0になった時の一括状態リセットでは、解除ポップアップを表示しません。通常の解除ポップアップと、戦闘不能状態の付与ポップアップは従来どおり表示します。

## 攻撃後の状態付与と付与率

スキルの「管理タグ＋メモ」欄に次のタグを追加すると、攻撃の効果が発生してから最低1秒待ち、攻撃エフェクトとダメージ表示が終わった後に状態を付与します。

```
#攻撃後状態付与
```

同じ欄のメモ行に `状態付与率: 数値%` を記述すると、設定した確率で状態付与を抽選します。タグを付けず、付与率だけを設定することもできます。

```
#攻撃後状態付与
状態付与率: 50%
```

- 付与率は0～100の範囲で扱います。範囲外の値は0または100に補正します。
- 複数の状態を付与するスキルでは、状態ごと・対象ごとに個別に抽選します。
- 付与率の指定がない場合は100%です。
- 状態側や対象キャスト側に設定された耐性・付与可否の判定は、従来どおり別途適用されます。
