# CTB拡張タグ

## ボス撃破演出

モンスター（キャスト）の「タグ」欄に `#Boss` を追加すると、HPが0になった際、画面を2回フラッシュさせ、地鳴りのような効果音とともにモンスターを小刻みに左右へ震わせながら赤くします。その後、敵消滅効果音と設定済みの消滅エフェクトを再生します。タグは大文字・小文字を区別しません。

## 連続行動スキル

スキルの「タグ」欄に次のタグを追加すると、そのスキルが正常に実行された直後、使用者がもう一度行動できます。

```
#ctb_consecutive
```

- スキルのコストを支払えず実行に失敗した場合、連続行動は発生しません。
- 連続行動で同じタグ付きスキルを再度使うと、さらに連続行動できます。

## 空のスキル発動演出の省略

スキルの「タグ」欄に次のタグを追加すると、設定内容にかかわらず共通の発動演出を省略します。

```
#ctb_skip_activation
```

次の両方を満たすスキルは、共通の発動メッセージ、モーション、効果音、スキルカメラ、待機時間を省略して効果処理へ進みます。

- スキル固有の使用時メッセージが未設定
- ゲーム定義の「スキル発動エフェクト」が未設定

どちらか一方でも設定されている場合は、従来どおりの発動演出を行います。

## モーションとエフェクトの同期

スキルの「タグ」欄に次のタグを追加すると、スキル発動から20フレーム待って使用モーションを開始し、その開始に合わせて対象エフェクトの処理へ進みます。

```
#エフェクト同期
```

- スキルカメラは従来どおり先に開始します。
- 使用モーションは20フレーム経過後に開始します。
- 味方・敵・クリティカルの対象エフェクトは、使用モーションが開始したことを確認してから表示します。
- このタグがないスキルは従来どおりのタイミングで動作します。

## 発動待機の短縮

スキルの「タグ」欄に次のタグを追加すると、発動時の待機を約20フレームに固定し、スキルカメラの終了を待たずに効果処理へ進みます。

```
#短縮
```

- 決定ボタンやメッセージウィンドウの有無では20フレームより短くなりません。
- `#エフェクト同期` と同時に指定した場合は、モーションとエフェクトの同期処理を優先します。
- 以前使用していた `#近接攻撃` は短縮タグとして認識されません。

## スキル使用者の残像

スキルの「タグ」欄に次のタグを追加すると、使用者のスキルモーション中に残像を表示します。

```
#残像
```

- 2Dビルボードの使用者だけが対象です。3DモデルとLive2Dでは残像を表示しません。
- 残像は3フレーム間隔で生成され、15フレームかけてフェードアウトします。
- 同時に表示する残像は最大2枚、生成時の透明度は80%です。
- 残像は生成時の座標とモーション姿勢で停止し、本体とは別のビルボードとして描画されます。
- 使用者が前回の生成位置からほとんど動いていない場合は、同じ場所への重複生成を行いません。

## 状態変化ポップアップ

状態が付与・解除された時、対象キャストの近くに状態アイコンと名前を表示します。解除時の表示だけを省略したい状態には、次のタグを追加します。付与時の表示は通常どおり行われます。

```
#解除時非表示
```
