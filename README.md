# CTB拡張タグ

## 連続行動スキル

スキルの「タグ」欄に次のタグを追加すると、そのスキルが正常に実行された直後、使用者がもう一度行動できます。

```
#ctb_consecutive
```

- BAKINのタグ表記に合わせ、先頭に `#` を付けてください。
- タグは大文字・小文字を区別しません。
- 複数のタグは空白、カンマ、またはセミコロンで区切れます。
- スキルのコストを支払えず実行に失敗した場合、連続行動は発生しません。
- 連続行動で同じタグ付きスキルを再度使うと、さらに連続行動できます。

## 空のスキル発動演出の省略

スキルの「タグ」欄に次のタグを追加すると、設定内容にかかわらず共通の発動演出を省略します。

```
#ctb_skip_activation
```

次の両方を満たすスキルは、共通の発動メッセージ、モーション、効果音、スキルカメラ、待機時間を省略して効果処理へ進みます。

- スキル固有の使用時メッセージが未設定
- ゲーム定義の「スキル発動エフェクト」が未設定

どちらか一方でも設定されている場合は、従来どおりの発動演出を行います。

## CTBスタン

スタンとして扱うスキルの「タグ」欄に次のタグを追加します。

```
#ctb_stun
```

スキルが命中して効果を与えた対象のCTBゲージを `0.5` 減らします（下限は `0`）。一度スタンを受けた対象は、その対象自身が次の行動機会を迎えるまでCTBスタンが無効になります。

CTBスタンを受けた時に解除したい状態の「タグ」欄には、次のタグを追加します。

```
#ctb_stun_cancel
```

例えば「危険行動準備中」にこのタグを設定すると、CTBスタンが有効になった時点でその状態を解除します。スタン耐性中はゲージ後退も状態解除も発生しません。
